# Laptop Request Item – ServiceNow Project

This project was developed as part of the Naan Mudhalvan program using ServiceNow.  
It automates the process of requesting laptops through the Service Catalog, including approval, assignment, and closure workflows.

## Contents
- **Brainstorming, Idea Generation, Prioritization Template** – Idea selection and planning document.  
- **Empathy Map Canvas** – Understanding user needs and challenges.  
- **Problem Statement Definition** – Defines the main problem addressed by the project.  
- **Performance Testing** – Documents testing, accuracy, and validation results.

## Tools and Platform
- Platform: ServiceNow  
- Modules Used: Service Catalog, Flow Designer, Business Rules  
- Testing: Manual and Performance Validation  

## Summary
The Laptop Request Item project streamlines IT asset requests by ensuring an efficient approval process, proper fulfillment tracking, and reliable closure.  
It enhances transparency, reduces delays, and improves user satisfaction.
