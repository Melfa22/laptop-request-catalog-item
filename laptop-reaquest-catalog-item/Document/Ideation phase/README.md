# 💻 Laptop Request Item – Naan Mudhalvan ServiceNow Project

## 📘 Project Overview
This project was developed as part of the **Naan Mudhalvan** course in collaboration with **ServiceNow**.  
The objective of the project is to design and implement a **Laptop Request Item** within the ServiceNow platform, allowing employees to request laptops through a streamlined, automated workflow that includes approval, fulfillment, and closure processes.
